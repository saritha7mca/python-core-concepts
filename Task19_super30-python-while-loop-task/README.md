# super30-python-while-loop-task

This repository contains Python programs focused on **condition-controlled iteration** using the `while` loop.  
The objective of this task is to understand when `while` is more appropriate than `for`, especially in situations where the number of iterations is **unknown** or **depends on user input**.

Each program is written with:
- Clear initialization, condition, and update steps  
- Comments explaining the logic  
- Clean, beginner-friendly structure  
- Independent execution (each file runs on its own)

---

## 📌 Topics Covered

### ✔ Basic while-loop iteration  
- Print numbers from **1 to 100**  
- Print numbers from **100 to 1**  
- Print **even numbers** between 1–100  

### ✔ Number processing  
- Sum of digits  
- Reverse an integer  
- Count digits  
- Factorial using while  

### ✔ User-controlled loops  
- Repeated input until user enters **0**  
- Password checker (loop until correct password)  
- Guessing game (loop until correct guess)
