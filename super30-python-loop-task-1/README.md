# super30-python-loop-task-1

This repository contains beginner-friendly Python loop programs covering:
- for loops
- range()
- strings
- lists
- tuples
- sets
- dictionaries

Each file is independent and includes comments explaining the logic.

Programs included:
1. Print numbers 1–100
2. Even numbers
3. Odd numbers
4. Multiplication table
5. Sum of numbers
6. Factorial
7. Divisible by 3
8. Language lengths
9. Dictionary iteration
10. Vowel count
11. Reverse string using loop
12. Largest number without max()

Sample input/output is shown inside each program.
